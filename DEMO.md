# MURENA local demo runbook

## Preflight

```bash
uv sync
npm --prefix frontend install
uv run python backend/data/metadata/create_demo_dataset.py --force --n 1500
```

Keep `backend/.env` local and out of Git. For this notebook it should use:

```text
LLM_PROVIDER=gemini
LLM_MODEL=gemini-3.5-flash
DATASET_FULL=data/metadata/estates.parquet
```

Do not paste API keys into committed files.

## Start

```bash
uv run python run_app.py --skip-init
```

Open the frontend URL printed by the launcher. If port `5173` is already in
use, the launcher chooses the next free port, for example `http://localhost:5174`.

Default login:

```text
username: admin
password: admin
```

## Suggested demo flow

1. Login as `admin/admin`.
2. Open the home search.
3. Click one suggested query or use:

```text
Edifici di almeno 1000 mq vicino al Politecnico
```

4. Start the analysis and wait for the processing page.
5. Open the map/results page and show:
   - ranked candidates,
   - energy scores on a 4-20 point scale,
   - proximity/context scores,
   - agent trace or logs if asked.

## Data notes

The local parquet contains 1500 synthetic Turin buildings generated by
`backend/data/metadata/create_demo_dataset.py`. It is schema-complete and useful
for a functional demo, but it is not the research dataset from the paper.

Energy score totals are generated on the same 4-20 scale used by the UI and the
real dataset pipeline.
