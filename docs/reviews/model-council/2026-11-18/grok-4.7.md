## 6. Questions a PC member is likely to ask

1. **What does the EVPI order change?** Nothing in the reported metrics. Every unconfirmed omission is still asked (`service.py:719-734`); cooperative runs take exactly \(k\) turns. The order is a SAGE-Agent heuristic with uniform weights (`uncertainty.py:30-37`). Suggested answer: say that in the demo script, and do not imply that 0.88 measures the ordering.
2. **Why is refined-versus-one-shot not a dialogue-versus-form result?** The cooperative user supplies the omitted fragment verbatim (`tex:308-309,363-366`). The gap is the value of that information under this pipeline. Suggested answer: keep the scope paragraph; do not add a form baseline you have not run.
3. **Is the oracle relevance ground truth?** No. It is a reference query analysed by the same pipeline (`tex:327-328`). Suggested answer: repeat that sentence if a reviewer treats Jaccard as NDCG against judged properties.
4. **Why does Figure 2 show 144 properties?** It is not a run from `missingness_v3_haiku_r2`. Suggested answer: replace the figure, or label it as a different live session and cite 16 for the logged case.
5. **Which logs will the offline booth show?** In this commit, 75 v4 seed-13 scenarios (`benchmark_runs.json`), from a series the paper says was not evaluated. Suggested answer: retarget the export before the demo, and do not mix those rankings with Table 1.
6. **Where is the video, and does it match the walkthrough?** Unverified. The repo has a silent GIF that the README says includes a vague answer and an opt-out, which is a different script from the cooperative two-question walkthrough in `tex:290-298`. Suggested answer: the MP4 should show both the cooperative nursery path and one opt-out or vague turn, and its result list should match the run you discuss.
7. **Were the series pooled?** Not in the active source. Cooperative metrics use `missingness_v3_haiku_r2` only. Non-English input is not rejected; questions are still prompted in English (`prompts.md:60-62`). Suggested answer: demo in English, and do not revive the Italian sentence.

Suggested answer: the residual is pipeline variability on this model and date, not a claim of perfect recovery or of stable rankings under another model.
