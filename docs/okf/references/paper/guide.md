# Guida ai sorgenti del manoscritto

Questa directory conserva copie dei sorgenti LaTeX **forniti dall'utente** per verificare definizioni, formule e numeri della parte ricerca:

- [`paper.tex`](paper.tex): testo principale e tabelle delle metriche.
